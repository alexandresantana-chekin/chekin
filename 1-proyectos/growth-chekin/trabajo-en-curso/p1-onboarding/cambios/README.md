# Fichas de cambio

Un archivo por cambio: `AAAA-MM-DD-nombre-corto.md`, con esta plantilla.

```
# Nombre del cambio
- Pedido por / origen:
- Qué cambia (pantallas):
- KPI que mueve (de kpis.md):
- Hipótesis:
- Riesgos (legal, ventas):
- Revisión de personas: revisiones/…
- QA: pasa / no pasa
- OK de Alex: fecha
- Versión publicada:
- Resultado medido (fecha y periodo):
```
